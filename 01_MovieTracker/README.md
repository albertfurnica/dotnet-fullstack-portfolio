MovieTracker
A modern, full-stack movie management web application inspired by Letterboxd, built to help film enthusiasts track their watchlists, log watched movies, and manage their cinematic database seamlessly.

✨ Features
User Authentication & Dashboard: Secure login/register flow with a dedicated user info management panel.

Watchlist & Watched Logs: Easily toggle between movies you want to watch (To Watch) and films you've already seen, with instant status updates.

Instant Client-Side Search: Real-time search bar embedded right into the header to filter titles instantly as you type.

Advanced Sorting: Sort your movie grid dynamically by Title (A-Z, Z-A), Release Year, or Rating.

Admin Control Panel: A clean, dark-mode dashboard providing full CRUD (Create, Read, Update, Delete) operations for both users and movies.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Flexbox, Custom Dark Mode UI), Vanilla JavaScript (ES6+).

Backend: RESTful API built with C# / .NET.

Icons & Assets: FontAwesome.
